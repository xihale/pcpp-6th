**MARC GREGOIRE** 是来自比利时的软件架构师。他毕业于比利时鲁汶大学，所获学位为“Burgerlijk ingenieur in de computer wetenschappen”（大致相当于计算机科学工程硕士）。次年，他在同一所大学以 *cum laude* 的成绩获得人工智能高级硕士学位。完成学业后，Marc 加入比利时的软件咨询公司 Ordina Belgium。作为顾问，他曾在 Siemens 与 Nokia Siemens Networks 参与面向电信运营商、运行于 Solaris 平台上的关键 2G 与 3G 软件开发工作。这类工作要求在横跨南美、美国、欧洲、中东、非洲与亚洲的国际团队中协作。如今，Marc 在 Nikon 旗下的 Nikon Metrology（`industry.nikon.com`）担任软件项目经理兼软件架构师。该公司是高精度光学仪器、X 射线设备以及用于 X 射线、CT 与三维几何检测的计量解决方案的重要供应商。

他的主要专长是 C++。他拥有在 Windows 和 Linux 平台上开发 24/7 持续运行的 C++ 程序的经验，例如 KNX/EIB 家居自动化软件。除 C++ 外，Marc 也很喜欢 C#。

自 2007 年 4 月起，他凭借在 Visual C++ 领域的专长，持续获得微软年度 MVP（Most Valuable Professional）荣誉。

Marc 还是比利时 C++ 用户组（`becpp.org`）的创始人，Apress 于 2016 年和 2019 年出版的 *C++ Standard Library Quick Reference* 第一、二版的合著者，多家出版社众多技术图书的技术编辑，以及 CppCon C++ 大会（`cppcon.org`）的常邀演讲者。他在 `www.nuonsoft.com/blog` 上维护博客，并热爱旅行与美食餐厅。

## 关于技术审校

**BRADLEY JONES** 使用过多种编程语言与工具，覆盖范围从 C 到 Unity，运行平台从 Windows 到移动端，也包括 Web，此外还出于兴趣涉猎了一些虚拟现实与嵌入式设备开发。除了编程以外，他还撰写过 C、C++、C#、Windows、Web 等大量技术主题图书，以及少量非技术类作品。Bradley 是 Lots of Software, LLC 的负责人，在业内既被视为社区影响者，也曾获得 Microsoft MVP、CODiE Judge、国际技术讲师、畅销技术作者等多项认可。

**ARTHUR O'DWYER** 是职业 C++ 培训师、软件工程师、作者，同时也是 WG21 委员会成员。他著有 *Mastering the C++17 STL*（Packt Publishing，2017），创立了 CppCon 的 “Back to Basics” 专题（2019），实现了 libc++ 的 `<memory_resource>` 头文件（2022），并推动了 C++20 与 C++23 中更简化的“隐式移动（implicit move）”语义。他与妻子居住在纽约。
