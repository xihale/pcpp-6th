C++23 标准库的接口由 107 个头文件组成，其中有 21 个对应 C 标准库。从 C++23 开始，你只需导入命名模块 `std`，即可访问整个标准库；本书中的所有示例也都是这样做的。除少数不可导入的头文件（例如 `<cassert>`）外，已经不再需要显式导入或包含单独的头文件。不过，如果你的编译器尚未支持 C++23 的命名模块 `std`，那么你仍然需要导入或包含相应的头文件。在这种情况下，往往很难记清源代码中究竟该包含哪些头文件，因此本附录按八个类别，对每个头文件中最有用的功能做了简要说明：

- C 标准库
- 容器
- 算法、迭代器、范围与分配器
- 通用工具
- 数学工具
- 异常
- I/O 流
- 线程支持库

## C 标准库

C++ 标准库几乎完整地包含了整个 C 标准库。这些头文件与 C 中的版本大体相同，主要有以下两点区别：

- 头文件名采用 `<cname>`，而不是 `<name.h>`。
- 在 `<cname>` 头文件中声明的所有名称都位于 `std` 命名空间中。

:::note
如果你愿意，仍然可以包含 `<name.h>`；但那样会把这些名称放入全局命名空间，而不是 `std` 命名空间。此外，在 C++23 之前，使用 `<name.h>` 形式的 C 标准库头文件已被弃用。从 C++23 开始，它们不再被视为弃用，但仍不推荐使用。
:::

:::note
C 标准库头文件并不保证可以通过 `import` 语句导入。因此，应使用 `#include <cname>`，而不是 `import <cname>;`。当然，使用 `import std;` 也会让 C 标准库中的全部内容在 `std` 命名空间中可用，但像 `<cassert>` 中的 `assert()` 这类宏除外。
:::

下表列出了所有 C 标准库头文件，并概述了它们最常用的功能。请注意，通常建议尽量避免直接使用 C 风格功能，而在可能的情况下优先使用等价的 C++ 特性：

| 头文件 | 内容 |
| --- | --- |
| <cassert> | `assert()` 宏。 |
| <cctype> | 字符判定与字符处理函数，例如 isspace() 和 `tolower()`。 |
| <cerrno> | 定义 errno 表达式，这是一个宏，用于获取某些 C 函数最近一次错误的错误码。 |
| <cfenv> | 支持浮点环境，例如浮点异常、舍入模式等。 |
| <cfloat> | 与浮点算术相关的 C 风格宏定义，例如 FLT_MAX。 |
| <cinttypes> | 定义了若干可与 printf()、`scanf()` 及类似函数配合使用的宏。此头文件还提供了一些用于处理 `intmax_t` 的函数。 |
| <climits> | C 风格的范围宏定义，例如 INT_MAX。推荐改用 `<limits>` 中对应的 C++ 版本。 |
| <clocale> | 少量本地化相关的宏与函数，例如 LC_ALL 和 `setlocale()`。另请参见 `<locale>` 中的 C++ 对应功能。 |
| <cmath> | 数学工具，包括三角函数、sqrt()、`fabs()` 等。 |
| <csetjmp> | setjmp() 和 `longjmp()`。在 C++ 中千万不要使用它们！ |
| <csignal> | signal() 和 `raise()`。在 C++ 中应避免使用。 |
| <cstdarg> | 用于处理可变长度参数列表的宏和类型。 |
| <cstddef> | 重要常量，例如 NULL；以及重要类型，例如 `size_t` 和 `byte`。 |
| <cstdint> | 定义若干标准整数类型，例如 int8_t、`int64_t` 等；还包含用于指示这些类型最小值和最大值的宏。 |
| <cstdio> | 文件操作，包括 fopen() 和 `fclose()`；格式化 I/O：`printf()`、`scanf()` 及其系列；字符 I/O：`getc()`、`putc()` 及其系列；文件定位：`fseek()` 和 `ftell()`。推荐改用 C++ 流。（参见本附录后文的“[I/O 流](#bapp03-sec-0010)”一节。） |
| <cstdlib> | 随机数 rand() 和 `srand()`（自 C++14 起已弃用；请改用 C++ 的 `<random>` 功能）。此头文件还包含 `abort()` 和 `exit()` 函数——应尽量避免使用；C 风格内存分配函数 `calloc()`、`malloc()`、`realloc()` 和 `free()`；C 风格查找与排序函数 `qsort()` 和 `bsearch()`；字符串转数字函数：`atof()`、`atoi()`；以及一组与多字节/宽字符串处理相关的函数。 |
| <cstring> | 底层内存管理函数，包括 memcpy() 和 `memset()`。此头文件还包含 C 风格字符串函数，例如 `strcpy()` 和 `strcmp()`。 |
| <ctime> | 与时间相关的函数，包括 time() 和 `localtime()`。 |
| <cuchar> | 定义若干与 Unicode 相关的宏，以及 mbrtoc16() 等函数。 |
| <cwchar> | 面向宽字符的字符串、内存和 I/O 函数版本。 |
| <cwctype> | <cctype> 中函数的宽字符版本：`iswspace()`、`towlower()` 等。 |

以下 C 标准库头文件自 C++20 起已被移除：

| 头文件 | 内容 |
| --- | --- |
| <ccomplex> | 仅包含 <complex>。 |
| <ciso646> | 在 C 中，<iso646.h> 会定义 `and`、`or` 等宏；而在 C++ 中，这些本身就是关键字，因此该头文件是空的。 |
| <cstdalign> | 与对齐相关的宏 \_\_alignas\_is\_defined。 |
| <cstdbool> | 与布尔类型相关的宏 \_\_bool\_true\_false\_are_defined。 |
| <ctgmath> | 仅包含 <complex> 和 `<cmath>`。 |
